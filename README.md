# Интерактивный тренажёр C#

Веб-приложение для изучения C# с теорией, практическими заданиями и системой
прогресса. Курс оформлен как путешествие по главам «Королевской академии кода».

## Возможности

- 12 глав: от основ языка и работы со строками до LINQ и асинхронности.
- 53 задания с выбором ответа, объяснениями и повторными попытками.
- Личные аккаунты, сохранение результатов, баллы опыта и достижения.
- Аналитика ответов, история попыток и рекомендации по повторению тем.
- 9 дополнительных заданий с вводом кода и разбором через API Groq.
- Адаптивный интерфейс в пиксельном стиле.

## Технологии

**Frontend:** React, TypeScript, Vite.  
**Backend:** Python, FastAPI, SQLAlchemy, Pydantic.  
**База данных:** SQLite.

## Установка и запуск

Требуются Python 3.13 и Node.js 22.18+ из ветки 22 либо Node.js 24+.
Команды ниже приведены для PowerShell и выполняются из корня проекта.

### Backend

```powershell
cd backend
py -3.13 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
if (!(Test-Path .env)) { Copy-Item .env.example .env }
.\.venv\Scripts\python.exe -m uvicorn app.main:app --reload
```

База данных и учебный каталог создаются автоматически при первом запуске.
Прогресс сохраняется в `backend/trainer.db`.

### Frontend

В отдельном терминале:

```powershell
cd frontend
npm ci
npm run dev
```

Приложение доступно по адресу [localhost:5173](http://localhost:5173).
Создайте аккаунт через форму регистрации. Документация API доступна по адресу
[127.0.0.1:8000/docs](http://127.0.0.1:8000/docs).

### Настройка наставника

Для разбора кода заполните `GROQ_API_KEY` в `backend/.env`. Переменная
`GROQ_MODEL` задаёт используемую модель. Если аккаунт Groq использует бесплатный
тариф, установите `GROQ_FREE_PLAN_CONFIRMED=true`, чтобы включить запросы.
После изменения настроек перезапустите backend. Без ключа основной курс работает.

Код отправляется в Groq по кнопке после согласия пользователя. Наставник
анализирует текст, не запускает программу и не начисляет опыт. Черновик
сохраняется в браузере отдельно для каждого аккаунта.

## Структура проекта

```text
backend/
  app/          API, модели данных, учебные материалы и логика обучения
  scripts/      Служебные команды для аккаунтов и проверки подключения
  tests/        Тесты API, авторизации, прогресса и учебного каталога
frontend/
  public/       Статические файлы
  src/          Компоненты, хуки, стили и клиент API
  tests/        Тесты запросов, переключения заданий и сохранения черновиков
```

## Проверки

В каталоге `backend`:

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
.\.venv\Scripts\python.exe -m pip check
```

В каталоге `frontend`:

```powershell
npm test
npm run lint
npm run build
```

Автотесты используют изолированные данные и не обращаются к Groq.
При установленном .NET SDK 8+ также проверяется компиляция примеров с классами
и интерфейсами. Без SDK эта проверка пропускается.
Сборка frontend создаётся в `frontend/dist`.

## Конфигурация

Пример настроек находится в `backend/.env.example`. Локальные настройки, ключи,
база данных, резервные копии и установленные зависимости исключены из Git.

При размещении приложения нужны HTTPS, `AUTH_COOKIE_SECURE=true`, адрес сайта
в `AUTH_ALLOWED_ORIGINS` и проксирование `/api` на backend с удалением префикса.
Текущие ограничения запросов рассчитаны на один процесс backend.
